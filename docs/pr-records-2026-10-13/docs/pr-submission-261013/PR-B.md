# 공통 잠금 안에서 SCons 캐시를 복구합니다

남은 `config.lock`이나 접근할 수 없는 캐시로 빌드가 막히는 문제를 처리하고, 복구와 다른 빌드가 같은 캐시를 동시에 변경하지 않도록 합니다. A 위에 적용하는 변경입니다.

## 변경 내용

- 캐시 밖에 유지하는 공통 `flock` 잠금을 빌드·정리·복구가 함께 사용합니다.
- 잠금을 확보한 상태에서 남은 잠금 파일이나 사용할 수 없는 캐시를 정리합니다. 빌드끼리는 잠금 해제를 기다립니다.
- 캐시를 지울 때에도 공통 잠금 파일은 유지합니다. 보호 범위는 이 잠금 규약을 따르는 프로세스입니다.

## 검증과 범위

- comma 4의 `626b887d`에 A+B+C를 적용한 실제 부팅에서 B의 두 복구 경로를 확인했습니다.
- 남은 `config.lock`만 제거됐고 캐시 표식과 기존 파일 345개의 내용은 보존됐습니다.
- `root:root`, 권한 `0700` 캐시는 관리자 권한으로 정리한 뒤 사용 가능한 캐시로 재생성됐습니다. 두 경우 모두 정상 기동했습니다. 남은 잠금 시험에는 별도의 외부 연결 오류가 기록됐습니다.
- 위 결과는 C의 손상 솔버 자동 복구 시험을 뜻하지 않습니다. C3x에서는 시험하지 않았지만 공통 캐시 처리이므로 기종 고유 특성에 대한 의존은 비교적 적다고 판단합니다.
