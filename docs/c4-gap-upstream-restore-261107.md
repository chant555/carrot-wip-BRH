# 추가 차간 여유 회복 로직의 상류 복원

2026-11-07 사용자 요청으로 추가 차간 여유의 거리 기준 회복을 제거했던 로컬 수정을 되돌렸습니다. 기준은 이미 반영된 상류 `0afb2eb3`입니다.

`longitudinal_gap_recovery.py`, `longitudinal_mpc_lib/long_mpc.py`, `test_longitudinal_gap_recovery.py` 세 파일 전체를 해당 상류와 동일하게 복원했습니다. 다른 실행 코드와 모델은 변경하지 않았습니다.

기준 거리는 차량 속도와 기본 추종 시간을 곱한 값에 설정된 정지 간격을 더한 값입니다. 실제 거리가 기준의 1.2배 이하이면 기존 유지 조건을 적용하고, 1.2배부터 1.5배 사이에서는 추가 여유의 유지·보충을 점진적으로 줄입니다. 1.5배 이상에서는 앞차가 멀어지거나 정지해 있어도 선택한 단계의 회복 시간척도를 적용합니다. 현재 상태와 미래 예측은 같은 기준을 사용합니다.

## 검증과 범위

- 차간 여유 회복·종방향 계획기·독립 SoftHOLD(정차 유지)·크루즈 버튼·대기 표시·정지 제어·가속도 변화율·원터치 제한 관련 검사 1,198개가 통과했습니다. 기기 의존 검사 6개는 제외했습니다.
- 거리 경계와 연속성, 정지·저속 앞차, 미래 예측과 현재 상태의 일치, 설정된 정지 간격 전달을 검사했습니다.
- 안내 문서는 이미 상류의 거리 구간과 회복 동작을 설명하므로 변경하지 않았습니다. 문서 검사는 검토 권고와 함께 통과했습니다.
- 독립 홀드, 원터치 4회, 저속 조향 완화, 정지 하한 밴드 선행 적용 취소, 웹 브랜치 전환 후 업데이트 대상 변경, 브랜치별 내장 모델은 유지합니다.
- 앞서 복원한 대기 판단·회색 표시·20초 타이머도 유지합니다.

과거 이 변경을 되돌린 이유와 주행 관찰 기록은 기존 커밋에 보존합니다. 이번 소프트웨어 검사로 실제 주행의 제동 빈도나 승차감이 개선됐다고 판단하지 않습니다. 이번 작업에서는 푸시·C4 적용·재부팅·주행 검사를 수행하지 않았습니다. 검사 원문은 작업 공간의 `analysis/2026-11-07-gap-restore/`에 보존합니다.
