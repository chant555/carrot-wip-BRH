## 충돌 해결과 기존 수정 보존

두 브랜치 모두 `desire_helper.py`의 가져오기 구문 한 곳에서 충돌했습니다. 상류의 `CommandReader, RUNTIME, read_json`, `BoundaryIndicator`와 기존 `OneTouchBlinkerLimit`를 모두 남겼습니다. 상류의 자체 램프 필터 처리 뒤에 기존 원터치 만료 판단이 이어집니다. 나머지 파일은 자동 병합됐습니다.

커밋 비교에서 원터치 제한 커밋만 새 가져오기 구문과 주변 문맥 차이를 보였으며 나머지 사용자 커밋의 패치는 동일했습니다. 상류 변경과 겹치지 않는 기존 사용자 수정 파일은 이전과 내용 식별자가 일치합니다. 상류와 겹치는 파일은 사용자 안내 4개, `car.capnp`, `carstate.py`, `carrot_settings.json`, `controlsd.py`, `desire_helper.py`입니다.

- 독립 SoftHOLD는 전진 기어에서 유효한 차속이 18km/h 이상이었던 이력이 있어야 합니다. 주차·후진·중립 등 전진 이외 기어에서 이력이 초기화됩니다. 정차·서행만으로 이력이 초기화되지는 않습니다.
- 새 SoftHOLD 진입은 조향각 절댓값 180도 미만에서 허용하며, 180도 이상에서는 차단합니다. 이미 유지 중인 홀드는 조향각 변화만으로 해제하지 않습니다. 크루즈 대기 상태에서도 같은 독립 홀드 조건을 유지합니다.
- 짧은 브레이크 재입력 해제와 기존 재진입 조건을 유지합니다. 독립 홀드가 크루즈를 자동 연결하지 않습니다.
- 일반 크루즈 연결·재개는 기존 70도·20도 조건과 대기 시간을 유지합니다. `_cruise_control`과 `_update_cruise_state`의 AST(추상 구문 트리)는 정정 기준 `ccacc384`와 같습니다. `cruise.py` 전체도 리베이스 전과 동일합니다.
- 원터치 방향지시등은 최대 4회 또는 3.2초 제한을 유지합니다. 예약 만료 시 후속 차로변경 예약과 토크 확인 면제를 해제하며 진행 중인 첫 차로변경의 조향은 유지합니다.
- 저속 차선 미사용 조향 곡률 평활화, 추가 차간거리 여유 구간 원복, 정차 진입 전 가속도 하한 변경 원복, 웹에서 전환한 브랜치를 따르는 업데이트 처리도 유지했습니다.
- `independentSoftHoldReady @112`를 유지했습니다. 상류의 다른 구조체 필드 추가와 충돌하지 않으며 검사에서 갱신된 메시지 스키마를 읽었습니다.
- 두 브랜치의 최종 파일 차이는 `openpilot/selfdrive/modeld/models/driving_supercombo.onnx` 하나이며, 각 모델은 리베이스 전과 동일합니다.
