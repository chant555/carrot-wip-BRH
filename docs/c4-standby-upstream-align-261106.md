# 2026-11-06 실제 크루즈 대기 판단을 상류와 통일

사용자 요청에 따라 아이오닉 5 PE 차종만 순정 MAIN 상태를 실제 크루즈 대기에 반영하지 않도록 했던 추가 조건을 제거했습니다. `_update_canfd_main_enabled` 함수는 상류 `38bd9f27`과 주석을 포함해 같습니다.

상류의 `HyundaiFlags.CAMERA_SCC` 조건을 그대로 사용합니다. 현재 C4처럼 카메라 기반 크루즈 구성에서는 순정 MAIN이 켜져도 실제 크루즈 대기가 켜지지 않으므로 동작이 같습니다. 아이오닉 5 PE이면서 이 플래그가 없는 구성에서는 이제 다른 차종처럼, 캐럿 가감속 제어·순정 MAIN 켜짐·수동 끔 잠금 없음 조건에 따라 대기를 켭니다. `AutoEngage` 초기화와 운전자 버튼 처리는 유지했습니다.

회색 대기 표시를 허용하는 `_stock_main_cluster`와 해당 `0x161` 표시 경로의 차종 제한 해제는 그대로입니다. 실제 대기와 표시를 분리하는 목적을 유지하며, SoftHOLD와 원터치 4회 관련 코드도 변경하지 않았습니다.

기존 차종·카메라 플래그 조합 검사의 기대값을 상류 조건에 맞췄습니다. 대기 분리·버튼·조향 준비·계기판·SoftHOLD·원터치 회귀 검사 888개가 모두 통과했습니다. 실제 대기 함수의 구문 구조가 상류와 일치하는 것도 확인했습니다. 두 브랜치에는 같은 변경을 적용하며 기존 주행 모델 차이는 유지합니다.

이번 작업은 코드 변경과 로컬 검사입니다. C4에는 적용하거나 재부팅하지 않았으며, 실제 주행 검증은 수행하지 않았습니다. 기기는 직전 적용 버전 `73fbe285`를 기준으로 별도 후속 적용이 필요합니다. 이전 배포 검사 스크립트의 `stock_main_sets_standby` 문자열 확인은 과거 버전용이므로 다음 배포에서는 상류 함수 일치와 카메라 플래그별 동작 검사로 대체해야 합니다.
