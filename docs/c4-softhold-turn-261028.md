# 독립 SoftHOLD 우회전 정차와 크루즈 대기 조향각 변경

작성일은 2026년 10월 28일입니다. 사용자는 우회전 중 횡단보도 신호 때문에 정차했던 17:08 전후에 독립 SoftHOLD가 재작동하지 않았다고 설명했습니다. 주행 기록에서는 조향각 약 129~164도가 당시 70도 진입 제한을 넘었습니다.

## 변경 동작

아이오닉 5 PE의 독립 SoftHOLD에는 조향각 진입 제한을 적용하지 않습니다. 전진 기어 전환 후 주행 이력 기준은 시속 16킬로미터에서 18킬로미터로 올립니다. 18km/h는 홀드가 작동하는 정차 속도가 아니라, 해당 전진 주행에서 한 번 도달해야 하는 준비 조건입니다. 실제 진입은 기존처럼 차속 0.1m/s 미만에서 브레이크를 약 0.61초 유지해야 합니다.

주차·후진·중립 등 전진 이외 기어로 전환하면 이력을 초기화합니다. D를 유지한 채 홀드 해제·서행·재정차하면 이력은 유지되므로 매번 18km/h까지 재가속할 필요가 없습니다. 짧은 브레이크 재입력 해제, 가속 페달 해제, 자동 크루즈 연결 차단, 차량 통신·준비 상태·순정 오토홀드·주차브레이크 조건은 유지합니다.

추가 사용자 지시에 따라 크루즈 연결과 대기 중 자동 재개의 조향각 경계도 180도로 바꿉니다. 조향각 절댓값이 180도 미만일 때 각 경로의 다른 조건을 만족하면 허용하고, 정확히 180도이거나 그 이상이면 차단합니다. 공통 연결 제한과 함께 브레이크 해제 후 자동 재개 경로의 기존 20도 조건, 대기 중 근접 앞차 판단의 기존 70도 조건을 같은 상수로 통일했습니다. 허용 각도만으로 크루즈가 자동 연결되는 것은 아니며 사용 가능 상태·취소 상태·기타 연결 조건을 계속 확인합니다. 자동 크루즈의 10초 타이머는 유지합니다.

## 검사 결과

관련 회귀 검사와 크루즈 일시정지 조합을 합쳐 502개가 통과했습니다. 네이티브 메시징 모듈에 의존하는 기존 검사 6개는 제외했습니다. 문서 생성 관련 검사 25개도 통과했습니다.

- 16km/h와 17.99km/h에서는 이력을 충족하지 않고, 정확히 18km/h와 그 이상에서 충족하는 경계를 확인했습니다.
- 조향각 ±70·±129·±164·±180·±200도에서 독립 홀드 진입, 가속 해제 뒤 재정차, 짧은 브레이크 재입력 해제와 자동 연결 요청 차단을 확인했습니다.
- 자동 크루즈의 연결·브레이크 해제 후 재개·대기 중 근접 앞차 경로에서 179.9도 허용과 ±180도 차단을 확인했습니다.
- 크루즈 일시정지 조합, 주차·후진·중립 초기화, 기존 정지 명령 생성과 원터치 방향지시등 4회 제한도 포함했습니다.

검사는 개인용 컴퓨터의 시험 대역과 실제 제어 함수·메시지 생성 함수를 사용한 회귀 검사입니다. 새로운 조건의 실차 작동 결과는 아닙니다. 원본 출력은 작업 공간의 `analysis/2026-10-28-softhold-turn/`에 보존합니다. 첫 추가 시험은 수정 전 조향각 진입에서 12개가 실패했고, 수정 후에는 시험 준비값 누락으로 같은 12개가 실패했습니다. 준비값을 보완한 뒤 위 최종 결과를 얻었습니다. 초기 출력도 보존합니다.
