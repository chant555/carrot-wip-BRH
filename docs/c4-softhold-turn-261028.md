# 우회전 정차 SoftHOLD 조향각 제한 정정

2026년 10월 28일 사용자 설명을 잘못 해석해 `bcd09ac`와 `0bd9a70`에서 독립 SoftHOLD의 조향각 진입 제한을 제거하고 일반 크루즈 연결·재개 조건을 180도로 확대한 변경을 정정합니다. 사용자가 뜻한 180도는 SoftHOLD 작동 조건입니다.

## 정정한 동작

- 아이오닉 5 PE의 독립 SoftHOLD는 크루즈 미연결·크루즈 사용 가능·일시정지 상태에서 조향각 절댓값이 180도 미만이면 다른 조건에 따라 준비하고, 180도 이상이면 새로 준비하지 않습니다.
- 주행 이력 기준은 D 전환 후 시속 18킬로미터 이상으로 유지합니다. 전진 이외 기어 전환 시 초기화하며 서행·정차·홀드 해제만으로 이력을 지우지 않습니다.
- 짧은 브레이크 재입력 해제와 홀드만으로 크루즈를 자동 연결하지 않는 동작을 유지합니다. 조향각 제한은 새 진입 조건이며 이미 유지 중인 홀드를 조향각만으로 해제하지 않습니다.
- 일반 크루즈의 공통 연결 제한은 기존 70도, 브레이크 해제 후 특정 재개 경로는 기존 20도, 대기 중 근접 앞차 분기는 기존 70도 조건으로 복원합니다. 일반 크루즈의 10초 타이머도 유지합니다.

## 검사

관련 회귀 검사와 크루즈 일시정지 조합 529개가 통과했고 기존 네이티브 메시징 의존 6개는 제외했습니다. SoftHOLD의 ±179.9도 허용·±180도 차단을 크루즈 사용 가능·제어 활성 여부 조합에서 검사했습니다. 우회전 재정차, 가속 해제, 짧은 브레이크 재입력, 기어 초기화와 방향지시등 4회 제한도 포함합니다.

일반 연결 함수 `_cruise_control`과 재개 판단 함수 `_update_cruise_state`의 구문 구조가 오해석 전 `ccacc38`과 같음을 확인했습니다. 이전 502개 통과는 잘못 해석한 요구사항에 맞춰진 검사였으므로 올바른 요구사항 충족의 근거로 사용하지 않습니다. 새 검사 결과는 로컬 검증이며 실차 주행 검증과 구분합니다.
