## 주요 발견

### 광각 카메라 지연 및 모델 입력 누락

- 시각: 2026-09-27 20:53:34 KST. 경로 주행-ea, 세그먼트 13.
- 광각 SOF timestamp 간격 95.44273 ms. 통상 약 50 ms. 해당 프레임 ID와 request ID는 1씩 증가했으므로 단순한 로그 프레임 ID 누락과는 다르다.
- 전방·운전자 카메라에는 같은 약 95 ms 간격이 없었다. 전후 3분 최대 간격은 전방 58.52 ms, 운전자 58.52 ms.
- modelV2 frameId가 15858에서 15861로 이동하고, 모델 로그는 camera dropped 1 frames; advancing model history를 기록했다. 이 두 지표의 정의가 다르므로 동일 개수로 해석하지 않는다.
- frameDropPerc는 최대 약 0.493%에서 점차 줄었다. 이후 많은 샘플에 0이 아닌 값이 남는 것은 필터의 잔여값이며 반복 누락 수가 아니다.
- 당시 약 73 km/h, gasPressed=True, latActive=True, longActive=False. selfdriveState.enabled=False여도 조향 보조는 활성 상태였으므로 완전 수동으로 해석하지 않는다.
- 전후 원본 3분에서 modelV2/cameraOdometry/livePose의 메시지 무효, pose inputsOK/sensorsOK/posenetOK 실패, CAN·레이더 오류는 없었다. 요약 로그에서도 고장에 의한 제어 해제 이벤트는 확인되지 않았다.
- SOF는 드라이버가 기록한 timestamp다. 센서 고장·노출 설정·CPU 경합·이번 Pull이 원인이라고 이 증거만으로 확정하지 않는다.

### Panda/CAN 및 SPI

- 네 주행 모두 registerDivergent를 포함한 Panda faults 없음.
- qlog 기준 heartbeatLost, safetyRxChecksInvalid, CAN invalid/timeout, 조향/ACC 고장, 버퍼 넘침 보고 없음. safetyRxInvalid/safetyTxBlocked 및 CAN 오류 누적의 주행 중 증가 없음.
- SPI checksum 카운터 증가는 각각 +4/+32/+2/+24, 합계 +62. 카운터 상승만으로 실제 CAN 전달 중단이나 물리 배선 잡음을 단정하지 않는다.
- 최신 MDPS/TCS 카운터 수정이 설치되어 있지만 CAN 메시지 순번의 전수 검증은 이번 점검 범위에 포함하지 않았다. 따라서 이번 결과만으로 해당 수정의 실차 검증 완료라고 표현하지 않는다.

### 기타

- GPS almanac 저장 실패/NACK 쌍이 11/8/4/27회, 합계 50회. 실시간 위치 수신과 별개의 저장 명령 실패이며 GPS fix 품질은 이번 점검에서 정밀 재분석하지 않았다.
- 시작 약 6.6~7.5초에는 pose inputsOK 실패와 초기화 경고가 있었으나 이후 요약 로그에서 같은 유효성 실패는 없었다.
- athenad WebSocket 연결 종료가 일부 기록되었다. 해당 시점 차량 제어 해제로 연결되는 증거는 확인되지 않았다.
- 최신 자동 Safe 복귀 변경은 현재 MyDrivingModeAuto=0 설정에서 적용되지 않는다.

### 비교 해석

1. **Panda 결함 미관측이 두 표본에서 이어졌다.** 이전·현재 커밋 모두 실제 주행에서 registerDivergent가 없었다. 이번 Pull로 새로 해결된 항목은 아니다.
2. **SPI 오류 증가 빈도는 이번 표본에서 낮았다.** 시간·거리로 보정해도 낮지만, 같은 경로·교통·체결 횟수·전원 상태로 통제한 비교가 아니다. 오류가 짧게 몰려 발생하는 특성도 있어 장거리 고속 주행에서 거리당 수치가 낮아질 수 있다. MDPS/TCS 카운터 수정이 원인이라고 단정하지 않는다. 카운터는 고장 횟수 자체가 아니다.
3. **새로 관측된 주의 항목은 광각 카메라 지연이다.** 9/26에는 없었고 이번에는 1개 사건이 확인됐다. 다만 관측 시간이 약 4.7배 길고 도로·조명 조건이 다르며 이번 커밋은 카메라/모델 코드를 바꾸지 않았다. 회귀 또는 무관함 어느 쪽도 확정하지 않는다. 이전 C4 조사에 유사한 약 95~100 ms 간격 사례가 있었지만 동일 원인으로 결론 내리지 않는다.
4. **처리 성능이 크게 변했다는 근거는 없다.** 모델 평균은 양쪽 모두 약 30 ms다. 이전은 원본 전수, 현재는 요약 표본이므로 소수점 수준 차이를 성능 개선으로 보지 않는다. 온도 차이도 외기·주행 조건의 영향을 통제하지 못했다.
5. **자동 Safe 복귀 개선은 이번 결과로 검증할 수 없다.** 전후 점검의 MyDrivingModeAuto는 0(OFF)였다. 해당 설정의 주행 중 변경 이력을 전수 복원하지 않았으므로 운전자 체감 개선을 이 기능에 귀속하지 않는다.
6. **MDPS/TCS 수정의 직접 검증은 남아 있다.** 현재 주행에서 통신 고장 징후는 없지만, 기존 주행도 CAN 오류는 없었다. 실제 camera-bus 송신 카운터 연속성과 CRC를 전후 CAN 원본으로 비교해야 해당 변경의 효과를 직접 평가할 수 있다.
7. **GPS 저장 실패는 계속된다.** 횟수 증가는 주행 시간이 길어진 영향과 함께 봐야 하며, 이번 커밋이 GPS를 개선하거나 악화시켰다는 증거는 없다.
