# 2026-11-05 순정 MAIN 계기판 대기 표시의 차종 제한 해제

사용자 요청에 따라 `create_ccnc_messages`의 `0x161` 회색 대기 표시 예외에서 아이오닉 5 PE 차종 제한을 제거했습니다. 이 메시지 경로를 사용하는 모든 차종에서 종방향 제어가 활성화된 구성이고 순정 MAIN이 켜졌으며 운전자의 수동 MAIN 끔 잠금이 없으면 대기 표시를 허용합니다. 다른 제조사의 별도 계기판 프로토콜을 추가한 것은 아닙니다.

실제 `cruiseState.available`이나 제어 활성 상태를 변경하지 않습니다. `carstate.py`의 카메라 기반 크루즈 대기 분리와 기존 C4 전용 조건은 그대로입니다. 초기 `AutoEngage` 설정, MAIN·SET·RES 버튼 처리, SoftHOLD와 원터치 제한도 변경하지 않았습니다. 순정 MAIN 꺼짐·수동 끔·종방향 제어 비활성 구성에서는 표시 예외가 적용되지 않습니다.

검사 729개가 통과했습니다. 현대 계열 등록 차종 식별값 전체를 같은 메시지 시험 환경에 넣어 차종 제한 부재, 기존 실제 대기 화면과의 메시지 일치, 예외 차단 조건과 실제 대기·제어 상태 불변을 확인했습니다. 이는 해당 차종 모두가 실제로 이 메시지 경로를 사용하거나 같은 화면을 표시한다는 실차 검증은 아닙니다. 상류 대기 분리 및 기존 계기판 회귀 검사도 포함했습니다.

작업 증거는 `analysis/2026-11-05-cluster-all/`에 보존합니다. 두 브랜치에 같은 변경을 반영하며 이번 표시 범위 확대에 대한 기기 적용·재부팅·실차 화면 검증은 수행하지 않았습니다.
