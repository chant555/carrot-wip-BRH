# 독립 SoftHOLD의 전진 주행 이력 조건 — 2026-10-27

## 변경 이유와 동작

주차 조작 중 예상하지 않은 홀드를 줄이기 위해 아이오닉 5 PE의 독립 SoftHOLD 진입 조건을 전진 기어 전환 후 10초 대기에서 시속 16킬로미터 이상 주행 이력으로 바꿨습니다. 정차한 채 시간이 지나도 주차 조작 중일 수 있다는 사용자 요청을 반영했습니다.

- 전진 기어에서 유효하고 시간 초과가 없는 차량 통신으로 읽은 유한한 차속이 시속 16킬로미터 이상이면 해당 전진 주행의 이력을 기억합니다. 최초 준비 상태는 거짓이며 프로그램 재시작 후에도 새 주행 이력이 필요합니다.
- 주차·후진·중립 등 전진 이외의 기어에서는 이력을 초기화하고 독립 홀드 준비·유지를 해제합니다. 다시 전진으로 바꾼 뒤 기준 속도에 도달해야 합니다.
- 전진 기어를 유지하는 동안 감속·정차하거나 짧은 브레이크 재입력으로 홀드를 해제해도 주행 이력은 유지합니다. 따라서 그 뒤 충분히 브레이크를 유지하면 다시 홀드가 준비되며 재가속은 필요하지 않습니다.
- 기존 통신·제어 준비·정차·페달·순정 오토홀드·주차브레이크·큰 조향각 조건과 약 0.61초의 브레이크 유지 조건은 그대로입니다. 최초 크루즈 버튼 조작과 무관하게 홀드만 유지하고 크루즈를 자동 연결하지 않습니다.
- 자동 크루즈의 `autoCruiseControl_cancel_timer`는 10초 그대로입니다. 독립 홀드만 이 타이머 대신 주행 이력으로 판정합니다. 다른 차종의 기존 홀드 시간 조건과 크루즈 버튼에 의한 타이머 해제도 유지합니다.

출발부터 계속 시속 16킬로미터 미만인 정체 구간에서는 독립 홀드가 준비되지 않습니다. 이미 기준 속도에 도달한 뒤 전진 기어를 유지한 채 주차장에 진입하면 허용 상태가 유지됩니다. 주행 이력 조건을 모든 주차 상황을 식별하는 기능으로 설명하지 않습니다.
