| 폴더 | 내용 |
|---|---|
| `2026-11-08-drive128/` | 주행 `00000128--996b87d9ef`(2026-11-07, `aggressive`)의 정체 구간 분석입니다. 정체 구간 표본(`data/l128_p0.csv`, `l128_p1.csv`), 접근 거리 분석(`closing/`), 재현 계산 결과 15조건(`replay/`), 그래프와 해시가 들어 있습니다. 이 주행에서 감속 작업이 시작되었습니다. |

- 파일은 작업 공간의 원본과 바이트 단위로 같습니다. 그래서 스크립트 안의 상대 경로와 글꼴 경로는 작업 공간 구조(`analysis/<날짜-주제>/`)를 기준으로 합니다.
- 위치 정보(GPS)는 들어 있지 않습니다.
- 사례 형식은 decel-2 시뮬레이션의 `cases130.json.gz`와 같습니다. 시뮬레이션 사본은 decel 빌드 계산기(매개변수 9개, 제약 5개)에 맞춰져 있습니다. 그래서 `decel-2` 계산기(매개변수 8개, 제약 4개)가 있는 기기에서 돌리려면 시뮬레이션 사본을 먼저 다시 만들어야 합니다.
